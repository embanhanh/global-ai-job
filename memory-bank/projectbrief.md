# Project Brief: Global AI Job Board

## Project Overview

Nền tảng tuyển dụng thông minh (Global AI Job Board) hỗ trợ đa ngôn ngữ (Tiếng Việt & Tiếng Anh), tích hợp trí tuệ nhân tạo (AI) để tối ưu hóa quá trình kết nối giữa ứng viên và nhà tuyển dụng.

## Core Goals

1.  **AI Integration**: Tự động phân tích, tóm tắt CV (PDF/Markdown) và gợi ý việc làm thông minh.
2.  **Multilingual Support**: Hỗ trợ 100% Tiếng Việt và Tiếng Anh xuyên suốt ứng dụng.
3.  **App Router & Server-First**: Xây dựng trên Next.js 15+ (hiện tại là 16) với kiến trúc ưu tiên Server Components.
4.  **Premium Experience**: Giao diện hiện đại, bóng bẩy (Dark mode, Glassmorphism, Animations).

## Key Features

- **Auth Flow**: Đăng ký/Đăng nhập đa phương thức, chọn vai trò (Candidate/Recruiter).
- **AI CV Sorting**: Nhà tuyển dụng có thể lọc hồ sơ bằng các câu lệnh ngôn ngữ tự nhiên hoặc tiêu chí AI.
- **Smart Dashboard**: Bảng điều khiển tùy chỉnh cho từng vai trò người dùng.
- **Job Detail Command Center**: Quản lý tập trung từng tin tuyển dụng với các tab: Ứng viên (DataTable), Nội dung (AI Scoring), Workflow (Kanban), và Analytics.
- **Follow & Push Notifications**: Hệ thống theo dõi công ty và nhận thông báo đẩy (FCM Topics) theo thời gian thực, đa ngôn ngữ.

## Scope

- Giai đoạn 1: Khởi tạo Project, cấu hình i18n và Auth UI (Hoàn thành).
- Giai đoạn 2: Tích hợp Supabase Auth & DB (Hoàn thành Core).
- Giai đoạn 3: Xây dựng AI CV phân tích và Jobs matching (Sắp tới).
- Giai đoạn 4: Quản lý Profile và Dashboard Candidate (Hoàn thành UI & Core Logic).
- Giai đoạn 5: Hệ thống RBAC & Layout Isolation (Hoàn thành).
- Giai đoạn 6: Nâng cấp Job Management & Applicant Tracking (Hoàn thành).
- Giai đoạn 7: Hệ thống Follow & Push Notifications (Hoàn thành).
- Giai đoạn 8: Job Analytics & Advanced AI Features (Sắp tới).
